# 성동구 음식점 폐업 위험: 경쟁 네트워크 · Cox · System Dynamics

서울시 성동구 일반음식점이 **주변에 어떤 가게가 얼마나 있을 때 더 빨리 문을 닫는지**를 생존분석(Cox)으로 추정하고,
그 위험 함수를 점포 수 시뮬레이션(System Dynamics, SD)에 넣어 **AI 입지 정보 활용과 무인·자동화 점포(피지컬 AI) 확산이 폐업을 어떻게 바꾸는지**를 시나리오로 비교한 연구의 코드·데이터·결과입니다.

- 논문: 「경쟁 네트워크 구조를 반영한 서울시 성동구 음식점 폐업 위험 분석과 입지 정보 활용 시나리오 시뮬레이션」, 김은혜\*·오은준\*·오주희\*\* (\*공동 제1저자, \*\*교신저자), 2026 한국정보기술학회 추계 종합학술대회
- 실행 환경: Python 3.9 이상, `pip install -r requirements.txt`

핵심 결과
- **집적(전체 음식점 수)은 일관되게 폐업 위험을 낮춥니다.** 100m 안 음식점이 10곳 많을수록 위험 7.9% 감소(HR 0.921, 모형 B). 네 반경 모두와 100m의 5개 기준일 모두에서 유의하고, 동 고정효과를 넣어도 유지됩니다.
- **동종 경쟁(같은 업태 수)은 본 분석에서 유의하지 않고**, 2023·2024년 코호트와 같은 동 안의 비교에서만 약하게 위험을 높입니다.
- **네트워크 지표의 추가 설명력은 100·200m 가중 연결강도에 한정**됩니다(C-index 개선 0.003).
- **진입을 내생화한 SD는 2022~2025년 점포 수를 −1.3~+1.9%로 재현**해 단순 모형(−5.5~−1.7%)보다 정확하지만, 점포 단위 판별력은 낮고(AUC 0.56~0.62) 2026년 진입 급감은 예측하지 못합니다.
- **AI 입지 정보**는 과거 반사실에서 누적 폐업을 3.5%(α = 40%) 줄이지만, 신규 점포의 40%가 자동화형이면 그 순효과가 약 3분의 1 줄고, 공실 수용 한도를 둔 2030년 예측에서는 0.5%로 작아집니다.

## 연구 설계

- **기준 집단**: 2021-04-01 영업 중인 성동구 일반음식점 **3,775개**
- **관찰 기간**: 2021-04-01 ~ 2026-10-13(인허가 데이터 추출일), 폐업 **1,677개(44.4%)**, 나머지는 우측 중도절단
- **Cox 분석 표본(①)**: 상권 매출이 결측인 808곳(업종 미분류 780곳 포함)을 제외한 **2,967개**(폐업 1,267개)
- **연도별 코호트(②~⑤)**: 2021~2025년 매년 4월 1일 기준 3,775 / 3,866 / 3,908 / 4,067 / 4,009곳, 같은 종료일까지 추적
- **연구 질문**
  - RQ1. 반경 기반 경쟁 변수를 통제한 뒤에도 경쟁 네트워크 구조가 폐업 위험을 추가로 설명하는가?
  - RQ2. 경쟁 효과는 반경과 관찰 기준일에 따라 어떻게 달라지는가?
  - RQ3. 위험 함수와 진입 피드백을 넣은 SD 모형은 과거와 2026년을 얼마나 재현하며, AI 입지 정보와 피지컬 AI 확산은 2030년까지 폐업을 어떻게 바꾸는가?
- **가설**
  - H1 (동종 경쟁): 같은 업태 이웃 수(C)와 비율(R)이 클수록 폐업 위험이 높다.
  - H2 (집적): 전체 음식점 수(BIZ)가 클수록 폐업 위험이 낮다.
  - H3 (공간 범위): H1·H2의 효과는 반경이 작을수록 크다.
  - H4 (네트워크): 반경 변수를 통제한 뒤에도 네트워크 지표가 폐업 위험을 추가로 설명한다.

## 주요 결과

### ① 기준 Cox (1~4단계)

통제 변수는 업력, 임대료 수준(low/mid/high), 상권 점포당 매출(log), 업태이고, 상권 단위 군집 강건 표준오차(72개 군집)를 썼습니다. 전체 수치는 [`outputs/results_summary.md`](outputs/results_summary.md)에 있습니다.

| 가설 | 결과 | 근거 |
|---|---|---|
| H1 동종 경쟁 | 기각 | C·R 모두 네 반경에서 5% 수준으로 유의하지 않음 |
| H2 집적 | 지지 | 100m 안 음식점 10곳당 HR 0.921(모형 B, 95% CI 0.899–0.944) |
| H3 공간 범위 | 부분 지지 | 표준편차 1당 BIZ의 HR이 100·200m 0.77·0.76 → 500m 0.84 |
| H4 네트워크 | 제한적 지지 | 100m(LR χ²(3) = 18.2, p < .001)·200m(10.0, p = .019)에서만 유의, 가중 연결강도만 위험 증가(1 SD당 HR 1.31, 1.17). 연결강도는 사실상 거리 가중 동종 밀도(C와 VIF 5~7), C-index 개선 0.003 |

- 반경 200m 음식점 수 상위 1/3 집단의 생존율은 64.6%로 하위 1/3(49.2%)보다 15.4%p 높습니다(log-rank p < .001).
- 결론은 임대료 처리 방식, 매출 변수 제외(전체 3,775곳), 밀집 상위 5% 제외, 일괄 폐업일 제외, 표준오차 보정 방식에 관계없이 유지됩니다(300m BIZ HR 0.967~0.978).
- Competitor_R의 비례위험 위반 신호(p = .013–.032)는 1년 구간별 시간가변 계수로 보완했고 결론은 같습니다(Wald p = .054–.219).

### ③ SD 시뮬레이션 (8단계)

```
S(t+1) = S(t) − D(t) + E(t)                         S: 영업 점포 수, D: 폐업, E: 신규
D(t)   = Σ pᵢ(t),  pᵢ(t) = 1 − exp(−exp(ηᵢ(t)))    점포별 1년 폐업 확률 (비례위험의 이산시간 형태)
ηᵢ(t)  = a + θ'Zᵢ + β_C·C₂₀₀(t)/10 + β_B·BIZ₂₀₀(t)/10
```

- C₂₀₀·BIZ₂₀₀은 그해 영업 점포로 매년 다시 세므로 폐업이 밀도를 낮춰 다음 해 위험을 높입니다(R1 집적 고리).
- 계수(점포-연 19,625건): BIZ₂₀₀ 10곳당 HR 0.969(p < .001), C₂₀₀ 1.026(p = .07). 회차마다 계수를 추정 분포에서 뽑아 200회 반복합니다.
- 실제 신규 점포를 넣으면 2022~2025년 점포 수 오차는 −1.7~+0.4%로, 평균 폐업률만 쓰는 단순 모형(−2.3~+0.7%)과 구별되지 않습니다. 이 한계는 ⑤에서 진입을 내생화해 보완했습니다.

정보 활용률 시나리오: 정보를 받은 신규 점포(비율 α)는 무작위 후보지 5곳과 원래 입지 중 예상 폐업 확률이 가장 낮은 곳을 고릅니다.

| α | 누적 폐업 2021→2025 (5~95%) | S0 대비 | 신규 점포 주변 200m 음식점 수 |
|---|---|---|---|
| 0% (S0) | 1,786 (1,713~1,863) | — | 93 |
| 40% | 1,724 (1,654~1,791) | −62 (−3.5%) | 145 |
| 60% | 1,689 (1,624~1,754) | −97 (−5.4%) | 183 |

정보를 받은 점포는 집적 효과가 큰 밀집지로 이동합니다. 혼잡과 수용 한도가 없어 낙관적인 값입니다.

### ④ 피지컬 AI 대체 시나리오 (10단계, 논문 표 4)

```
P(신규 점포 i가 자동화형) = min(1, ρ · w_업종 / 그해 신규 점포 평균 w)
BIZ*ᵢ(t) = BIZ₂₀₀ᵢ(t) − λ · (반경 200m 안 자동화형 점포 수)        ← ③의 위험식에서 BIZ₂₀₀ 대신 사용
```

- 업종 가중치 w: 리뷰 34,736건에서 구한 업종별 비대면 주문·포장·배달 언급률(`data/interim/category_automation_rates.csv`)을 전체 평균으로 나눈 값입니다.
- λ는 자료로 식별되지 않아(이웃의 자동화 성향 합과 BIZ₂₀₀의 상관 0.999) 0.5를 기준, 1.0을 민감도로 둡니다. ρ·λ는 가정입니다.

| ρ | λ | 자동화형(2025) | 누적 폐업 변화 (5~95%) | 밀집지 / 그 외 | α = 40% 순효과 |
|---|---|---|---|---|---|
| 0% | — | 0 | 기준 (1,786) | — | −62 |
| 20% | 0.5 | 263 | +8 (+3~+13) | +4 / +4 | −51 |
| 40% | 0.5 | 526 | +16 (+8~+25) | +8 / +8 | −40 |
| 20% | 1.0 | 263 | +16 (+8~+26) | +8 / +8 | — |
| 40% | 1.0 | 525 | +32 (+19~+46) | +16 / +16 | — |

정보가 있을 때 ρ = 40%의 추가 폐업은 16곳에서 22곳으로 늘고 밀집지(8 → 17곳)에 몰립니다. 정보를 받은 점포가 몰리는 밀집지에서 자동화형이 집적 이익을 잠식하기 때문입니다.

### ⑤ 피드백 확장 SD · 판별 검증 · 2030 예측 (12~14단계, 논문 표 3, 그림 2)

```
고리  R1 집적        폐업 → BIZ₂₀₀↓ → 다음 해 폐업 확률↑
      B1 유출        점포 수↑ → 폐업↑ → 점포 수↓
      B2 공실 재진입 폐업 → 공실 → 신규 진입(공실에 입점) → BIZ↑ → 위험↓
진입식  E_k(t) ~ Poisson(μ_k),  ln μ_k = a_k + τ + b·ln(D_k(t)+1)    (동 k, 그해 폐업 D_k)
```

- 진입식은 4월 기준 17개 동 패널(2016~2026)의 동·연도 고정효과 Poisson으로 추정합니다. 폐업에 대한 진입 탄력성 b = 0.26(p = .002, 2021년까지 학습). τ와 연도 충격은 최근 5개 연도 효과의 평균과 표준편차입니다.
- 예측의 정보 시나리오에서는 정보를 받은 점포가 빈 공실 5곳과 현재 입지 중에서 고르고, 공실 하나에 한 점포만 들어갑니다.

## 한계와 참고

- **SD 시나리오는 가정에 의존합니다.** 정보를 받은 사업자가 추정 위험을 정확히 안다고 가정했고, 집적 효과가 동보다 작은 단위의 입지 질을 대신 나타낸다면 밀집지 이동의 실제 효과는 더 작을 수 있습니다. ρ·λ·α는 추정값이 아닌 가정입니다.
- **⑤의 예측은 진입 충격을 예측하지 못합니다.** 2026년 홀드아웃에서 진입 급감으로 점포 수를 4.2% 과대 예측했으므로, 정책 예측은 절대 수준보다 시나리오 간 차이로 읽어야 합니다.
- Cox의 경쟁 변수는 기준일 값으로 고정되어 있습니다(코호트 분석과 SD에서 매년 다시 계산해 보완).
- 임대료는 2021년 1분기 값을 모든 코호트에 고정했습니다(2021-11 이후 자료 없음).
- 인허가 좌표는 건물(지번) 단위라 같은 건물의 점포는 좌표가 같습니다. 좌표를 끝내 찾지 못한 새 점포 8곳은 6단계에서 제외했습니다.
- 하루 20곳 이상이 폐업 처리된 날 4번(총 190곳)은 행정상 일괄 정리로 보고, 이 점포들을 제외한 강건성 검토를 ①에 함께 제시합니다.
- 리뷰 변수는 관찰 종료 시점의 영업 점포에만 있어 생존 모형에는 넣지 않고, 업종별 자동화 성향(④⑤)에만 씁니다.
- 상권 매출이 직접 관측되지 않은 971곳 중 943곳은 1km 이내 동일 업종 상권 매출의 역거리가중(IDW) 보간으로 채웠고, 업종 미분류 780곳과 보간 불가 28곳은 결측입니다.
- 코호트 파일과 최종 데이터에는 점포명·지번주소가 들어 있습니다(공개 인허가 자료).
